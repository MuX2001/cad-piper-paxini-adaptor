All new authored models, helpers, small validation records and requested final exports stay within `v2/`, following the project source/export separation. Large experiment outputs, if subsequently needed, belong under the existing workspace `runs/gripper-tac-cad/` convention. No third-party repository, package or environment was installed or modified.

The full GLBs use metres and contain the untouched base mesh, two source-selected carriers, new fingers, actual sensor geometry, unthreaded screw envelopes and the revised cable route. Amber plugs, loose-lead bundles, ties and service loops are authored clearance studies, not PaXini harness CAD. The pair STEP contains authored fingers, imported sensor B-reps and unchanged carrier triangles sewn into solids; the cable STEP contains eight separately named clearance solids. The mesh-only actuator stays in GLB. Print STL copies use proper rigid transforms documented in `interface-spec.md`; source units and scale are unchanged.

The existing 232-file preservation baseline is unchanged. The user-created `docs/goal/goal-02.md` is separately hashed as a subsequent input. Revised V2 reach, cable path, frame reinforcement, previews, exports and checks are regenerated from the V2 sources only.

Hirose's public plug STEP download was unavailable (HTTP 403), so no new vendor file was saved. The maximal rectangular plug envelope fits while mated, but its 8 mm straight sweep clips 1.316 mm³ of the existing sensor housing; this is recorded, not hidden or resolved by moving the socket. Printed holder and screw clearance along that corridor is verified. Actual stepped plug shape and physical latch/removal clearance must be checked before fabrication.
